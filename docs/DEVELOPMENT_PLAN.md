# Development Plan

## Phase 0: Runnable Skeleton

Status: complete

- Create React frontend.
- Create FastAPI backend.
- Initialize SQLite storage.
- Show an empty Projects page.
- Verify backend health.

## Phase 1: Project Workspace MVP

Status: complete

- Create, rename, and delete projects.
- Add project tabs for Goals, Plans, Tasks, Knowledge, Documents, and Reviews.
- Create Markdown documents.
- Upload files into local storage.
- Search project documents and material filenames.

## Phase 2: Section Editing

Status: not started

- Split Markdown documents into sections.
- Edit one section at a time.
- Show edit proposals and diffs before accepting changes.

## Phase 3: Version Management

Status: not started

- Save every accepted edit as a version.
- Compare versions.
- Roll back section-level changes.

## Phase 4: Codex Interface

Status: not started

- Add controlled tools for reading projects, searching material, creating plans, and proposing section edits.
- Keep AI writes behind explicit accept/reject review.
